Architecture

How Adaptive Transmission Works

Unlike fragile LSB steganography that breaks on standard uploads, ShadowPost combines frequency-domain DCT embedding with channel-aware pre-conditioning.

1. Pre-Conditioning

The cover image is snapped to the platform's exact native canvas (e.g. 1080px) and quality, preventing destructive spatial scaling.

2. Cryptographic Armor

Passphrase is converted to a 32-byte key via scrypt, then encrypted with AES-256-GCM with a 96-bit nonce.

3. Reed-Solomon Code

Data chunks are padded with parity bytes (RS), allowing the decoder to automatically correct flipped bits from quantization noise.

4. Native-DCT Embedding

Bits are embedded in relative frequency magnitudes (|A| > |B|) directly in the luminance DCT block lattice.
